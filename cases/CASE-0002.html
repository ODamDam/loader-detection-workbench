CASE-0002 분석 요약 — Amadey 파일을 품은 x64 드로퍼

2026-11-24 작성. 본문의 분석 내용은 분석가가 확정한 소견(FND-0006~0012)에 근거한다. 실행 조건과 룰 검증 수치는 Workbench에 저장된 기록이다. 원본 보고서와 로그는 공개하지 않는다.

2. 핵심 결과와 판정

가설(FND-0010): 샘플이 내장한 Amadey 파일을 %APPDATA%에 떨어뜨리고 예약 작업으로 지속성을 확보한다 — 판정: 지지됨(supported)

  • 샘플 안에 SMP-000004(x86, 432,128 bytes) 전체가 그대로 들어 있다. 위치는 파일 오프셋 12,288, .data 섹션의 시작이다. 봉인된 두 파일을 메모리에서만 비교해 확인했다(FND-0009).
  • 이 파일을 %APPDATA%\synchost.exe로 쓰고 실행했다. 이름은 svchost.exe를 흉내 낸 것으로 해석한다(FND-0006, FND-0010).
  • 작업 ID {2139AB6A-E164-43AA-9697-BE4E4124B009}로 파일 작성, 작업 등록, 재실행이 이어진다(FND-0011).
  • 판정 범위: 이 실행 안에서 작업 스케줄러가 파일을 다시 시작한 것까지 확인했다. 재부팅 뒤 실행은 시험하지 않았다.

4. 작동 원리(관측한 단계, FND-0012)

  1. 내장한 Amadey 파일을 %APPDATA%\synchost.exe로 쓰고 실행한다.
  2. 떨어뜨린 파일이 C:\Windows\Tasks\synchost.job을 작성한다.
  3. 작업 스케줄러가 그 파일을 다시 실행한다.

  • 재부팅 뒤의 지속성과 예약 작업의 전체 실행 조건은 확인하지 않았다.

  • 정상 비교는 YARA 2건, Sigma 5건의 Case로 적고 정상 설치 프로그램이 없다.

7. AI 의견의 처리

DeepSeek·Gemini의 의견 17건은 보고서 부록에 추론으로만 남겼고, 확정 소견의 근거로 쓰지 않았다. svchost.exe 흉내라는 해석은 AI 의견을 계기로 추가해 분석가가 채택했다. 샘플 바이트와 원본 로그는 전송하지 않았고 구조 요약만 사용했다.
