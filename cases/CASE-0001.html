2. 핵심 결과와 판정

가설(FND-0003): 샘플이 %TEMP% 아래 10자리 16진 이름 폴더에 자신을 복사하고 복사본을 실행한다 — 판정: 지지됨(supported)

  • 실행 파일과 복사본의 SHA-256이 같아 완전히 같은 파일이다(FND-0001).
  • 정적 분석한 파일과 실행된 프로세스의 SHA-256도 같아, 정적 특징과 동적 행위는 같은 파일에서 나왔다(FND-0004).
  • 판정 범위: 이 실행에서 관측한 복사와 재실행까지만 해당한다. 지속성 확보나 명령제어(C2) 통신은 판정에 포함하지 않는다.

4. 작동 원리(관측한 단계, FND-0005)

  1. 샘플이 시작된다.
  2. %TEMP% 아래에 10자리 16진 이름의 폴더를 만들고 자신을 복사한다.
  3. 복사본을 실행한다.

네트워크는 차단되어 있었다. 샘플과 복사본의 네트워크 연결(Event ID 3)과 DNS 조회(Event ID 22)는 Sysmon에 기록되지 않았다.

6. 한계와 확인하지 못한 것

  • 실행 1회, 최대 60초의 관측이다. 이후에 나타나는 행위는 알 수 없다.
  • 폴더 이름이 실행마다 달라지는지는 확인하지 않았다.
  • 네트워크를 차단했으므로 통신 기능의 동작은 확인하지 않았다. 정적 API 이름은 기능의 가능성일 뿐 사용의 증거가 아니다.
  • 정상 비교는 YARA 2건, Sigma 5건의 Case로 적고 정상 설치 프로그램이 없다.
