# 테스트 계획

## 1. 테스트 목표

- 핵심 파이프라인이 AI와 VM 자동화 없이도 동작함을 증명한다.
- 실제 악성 샘플 사용 전 시뮬레이터로 안전성과 재현성을 검증한다.
- 룰 검증 결과가 데이터셋과 버전에 따라 재현됨을 확인한다.
- 실패 상황에서도 부분 산출물과 오류 원인이 보존됨을 확인한다.

## 2. 테스트 계층

### 단위 테스트
- 파일 해시
- PE 결과 파싱
- Sysmon 이벤트 파싱
- 정규화 스키마
- 룰 상태 전이
- 지표 계산
- 경로 정규화
- 비식별화 함수

### 통합 테스트
- 프로젝트 생성부터 Case 등록
- Case Bundle 가져오기
- YARA 검사
- Sigma 이벤트 재현
- Markdown·HTML 생성
- SQLite와 파일 무결성
- Publication Bundle 생성

### 시스템 테스트
- VMware 스냅숏 복원
- 샘플 전달·해시 재검증
- PowerShell 오케스트레이터
- 타임아웃
- 결과 회수
- VM 복원
- `disabled`·`simulated` 네트워크 모드

### 인수 테스트
- 시뮬레이터 사례 1개 전체 완주
- 실제 악성 사례 1개 전체 완주
- 6개 케이스 정량 목표 충족
- 독립형 HTML과 정적 사이트 열람
- 공개 번들 민감 자료 점검

## 3. 핵심 테스트 시나리오

### 정상 경로
- 유효한 Sysmon 로그
- 유효한 YARA·Sigma
- 악성 탐지, 정상 비탐지
- 보고서 생성 성공

### 오류 경로
- 손상된 XML
- 중복 파일 등록
- YARA 문법 오류
- Sigma 지원하지 않는 필드
- VM 시작 실패
- 로그 회수 실패
- 스냅숏 복원 실패
- AI Provider 오류
- 보고서 템플릿 오류

## 4. 회귀 테스트

- 룰 수정 전후 동일 데이터셋 재검증
- 정규화 스키마 변경 시 기존 케이스 재처리
- 보고서 템플릿 변경 시 6개 케이스 일괄 빌드
- Publication Bundle에 금지 파일이 포함되지 않는지 검사

## 5. 테스트 데이터

- 무해한 시뮬레이터 프로필
- 정상 시뮬레이터 프로필
- 정제된 Sysmon 예제
- 정상 Windows 활동 로그
- 작은 정상 PE 파일 모음
- 공개 가능한 샘플 메타데이터
