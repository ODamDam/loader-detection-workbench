# 로드맵과 마일스톤

## 전체 원칙

VM 자동화나 AI보다 먼저 오프라인 코어 파이프라인을 완성한다. 각 마일스톤은 실행 가능한 산출물로 종료한다.

## M0. 문서와 저장소 기반

### 목표
개발 기준선과 작업 관리 체계를 만든다.

### 산출물
- 문서 세트
- ADR
- GitHub Issues·Milestones·Project Board
- 기본 저장소 구조
- 테스트 실행 골격

## M1. 프로젝트·케이스 코어

### 목표
프로젝트 작업공간과 Case를 생성하고 자료를 등록한다.

### 주요 작업
- 프로젝트 생성
- SQLite 초기화
- 상대 경로·해시 관리
- Case·Artifact 모델
- Case Bundle 가져오기
- CLI 골격

### 종료 조건
수동으로 케이스를 생성하고 자료를 등록할 수 있다.

## M2. 분석·정규화

### 목표
정적 PE 결과와 Sysmon 로그를 공통 케이스 모델로 변환한다.

### 주요 작업
- PE 분석 결과 모델
- Sysmon 파서
- 공통 이벤트 스키마
- 초기 실행 타임라인
- Evidence 연결

### 종료 조건
하나의 케이스에서 정적·동적 근거를 조회할 수 있다.

## M3. Detection-as-Code 검증

### 목표
YARA·Sigma를 악성·정상 데이터에서 검증한다.

### 주요 작업
- Detection Hypothesis
- YARA 문법·실행
- Sigma 문법·변환·오프라인 평가
- 정상 데이터셋
- ValidationRun
- 룰 상태·버전 관리

### 종료 조건
하나의 YARA·Sigma 룰 쌍을 검증하고 승인할 수 있다.

## M4. 보고서

### 목표
케이스 보고서를 자동 생성한다.

### 주요 작업
- Report Model
- Markdown 템플릿
- 독립형 HTML
- 정적 사이트
- 공개 번들

### 종료 조건
하나의 케이스 보고서와 사이트가 생성된다.

## M5. 시뮬레이터

### 목표
무해한 프로필로 동적 수집 파이프라인을 재현한다.

### 주요 작업
- 단일 실행 파일
- 내장 프로필
- 프로세스·파일·레지스트리·모의 네트워크 행위
- 정상 모드
- 결과 매니페스트
- JSON 설정 엔진 전환

### 종료 조건
시뮬레이터 케이스 1개가 전체 파이프라인을 완주한다.

## M6. VirtualBox 자동화 (향후, ADR-018)

### 목표
등록된 분석 VM 한 대에서 안전하게 자동 실행한다.

### 주요 작업
- VirtualBox Adapter (VMware는 향후 대안)
- VM 준비 상태 검사
- 스냅숏 복원
- 샘플 전달
- PowerShell 오케스트레이터
- 로그 회수
- 타임아웃·복구
- 네트워크 모드

### 종료 조건
사용자 승인 후 시뮬레이터가 자동 실행되고 결과가 회수된다.

## M7. AI Provider와 로컬 웹 UI

### 목표
분석 보조와 시각적 검토 기능을 추가한다.

### 주요 작업
- Manual·Mock Provider
- 외부 API Provider
- 로컬 LLM Provider
- AI 룰 초안
- 자동 검증
- 사용자 승인 UI
- 읽기·편집 웹 화면

### 종료 조건
AI를 끄거나 켠 상태에서 동일한 케이스를 처리할 수 있다.

## M8. 6개 평가 케이스와 공개

### 목표
수행계획서 정량 목표를 충족한다.

### 주요 작업
- 시뮬레이터를 실제 악성 사례로 순차 교체
- 6개 분석 케이스
- YARA 6개 이상
- Sigma 6개 이상
- 보고서 6편 이상
- 정적 사이트
- 공개 번들
- 최종 검수

### 종료 조건
정량 목표 증빙과 포트폴리오 시연이 가능하다.
