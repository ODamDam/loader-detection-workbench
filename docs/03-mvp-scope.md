# MVP 범위 명세서

## 1. MVP 정의

MVP는 여러 기능의 일부를 구현한 상태가 아니라, **하나의 케이스가 입력부터 룰 검증과 보고서 생성까지 완주하는 상태**이다.

## 2. MVP 단계

### MVP-A: 오프라인 코어 수직 슬라이스
필수 완료 단계이다.

```text
수동 Case Bundle 등록
→ 정적 PE 분석 결과 등록
→ Sysmon 이벤트 가져오기
→ 이벤트 정규화
→ 탐지 가설 수동 작성
→ YARA·Sigma 등록
→ 악성·정상 데이터 검증
→ Markdown·HTML 보고서 생성
```

### MVP-B: 시뮬레이터 기반 자동 실행
핵심 자동화 단계이다.

```text
내장 프로필 선택
→ 사용자 승인
→ 분석 VM 초기화
→ 시뮬레이터 전달·실행
→ 로그 회수
→ MVP-A 파이프라인 실행
```

### MVP-C: 평가용 완성도
학기 평가를 위한 목표 단계이다.

- 실제 악성 샘플로 시뮬레이터 케이스를 순차 교체
- 총 6개 이상 분석 케이스
- YARA 6개 이상
- Sigma 6개 이상
- 케이스별 Markdown·HTML 보고서 6편 이상
- 공통 정상 데이터셋과 사례별 정상 대응 데이터 검증
- 정적 보고서 사이트 생성

## 3. MVP 필수 기능

- 프로젝트 작업공간
- Case·Evidence·Rule·Validation 데이터 모델
- 정적 PE 결과 입력
- Sysmon 로그 파싱·정규화
- 수동 탐지 가설
- YARA 검사
- Sigma 오프라인 이벤트 검증
- 정상 비교 검증
- 룰 버전 관리
- Markdown·독립형 HTML 보고서
- CLI
- 무해한 시뮬레이터 내장 프로필
- Windows 분석 VM 1대 등록
- VirtualBox Guest Additions 기반 파일 전달과 향후 명령 실행 (ADR-018)
- 실행 승인·시간 제한·스냅숏 복원
- 네트워크 차단·모의 네트워크 모드

## 4. MVP 선택 기능

- Procmon 수집
- PCAP 수집
- 정적 사이트 검색·필터
- AI Mock Provider
- 외부 API 또는 로컬 LLM 1개 Provider
- 실험적 자동 룰 수정 반복

## 5. MVP 제외 기능

- 다중 분석 VM 동시 실행
- Hyper-V·VirtualBox 구현
- 실제 외부 인터넷 허용
- Office 문서·압축 파일·DLL 자동 실행
- 상시 실행 Guest Agent
- 실제 SIEM 적재
- 자동 룰 배포
- 계정·권한·다중 사용자 서버
- 최종보고서·논문 초안 자동 생성

## 6. 첫 번째 데모 시나리오

1. 프로젝트 생성
2. `SIM-001` 프로필 선택
3. 분석 VM과 네트워크 모드 확인
4. 사용자 승인
5. 3분 제한 실행
6. Sysmon 로그 회수
7. 정적·동적 증거 표시
8. 탐지 가설 작성
9. YARA·Sigma 등록
10. 정상 데이터 검증
11. 검증 상태 승인
12. Markdown·HTML 보고서 생성

## 7. MVP 종료 조건

- 하나의 시뮬레이터 사례가 자동 실행부터 보고서까지 완주한다.
- 하나의 실제 악성 사례가 동일한 파이프라인으로 완주한다.
- 실패 시 원인과 부분 산출물이 보존된다.
- AI 없이 모든 핵심 기능을 사용할 수 있다.
