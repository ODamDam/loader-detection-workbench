# 요구사항 명세서

## 1. 기능 요구사항

### FR-001 프로젝트 작업공간
- 프로젝트별 독립 폴더를 생성해야 한다.
- SQLite와 파일 시스템을 함께 사용해야 한다.
- 모든 등록 파일의 상대 경로와 SHA-256을 저장해야 한다.

### FR-002 케이스 관리
- 케이스 ID, 샘플 정보, 실행 프로필, 수집 상태, 분석 상태를 관리해야 한다.
- 케이스는 시뮬레이터, 실제 악성 샘플, 정상 비교 데이터로 구분해야 한다.

### FR-003 정적 PE 분석
- 모든 분석 케이스에서 해시, PE 헤더, 아키텍처, 섹션, Import, 문자열 등 기본 특징을 수집해야 한다.
- 결과는 구조화된 형식으로 저장해야 한다.

### FR-004 동적 증거 수집
- Sysmon은 모든 케이스의 필수 데이터이다.
- Procmon과 PCAP은 케이스별 선택 사항이다.
- 미수집 사유를 `not_required`, `not_applicable`, `collection_failed`, `not_configured` 등으로 구분해야 한다.

### FR-005 이벤트 정규화
- Sysmon과 선택적 로그를 공통 이벤트 스키마로 변환해야 한다.
- 프로세스, 파일, 레지스트리, DNS, 네트워크 이벤트를 시간순으로 구성해야 한다.
- 초기 실행 구간의 기본 분석 창은 3~5분이다.

### FR-006 탐지 가설
- 하나의 Detection Hypothesis에 정적 증거, 동적 증거, YARA, Sigma, 정상 반례, 한계점을 연결해야 한다.
- 근거 이벤트를 원본 자료와 연결해야 한다.

### FR-007 YARA 검증
- 문법 검사, 악성 파일 검사, 정상 파일 검사, 결과 저장을 지원해야 한다.
- 룰 버전과 변경 이유를 추적해야 한다.

### FR-008 Sigma 검증
- YAML·문법 검사와 변환 검사를 지원해야 한다.
- 정규화한 이벤트에 Sigma 조건을 적용하여 오프라인 탐지 결과를 재현해야 한다.
- 실제 SIEM 연동은 확장 후보이다.

### FR-009 정상 비교 검증
- 공통 정상 데이터셋과 사례별 정상 대응 데이터셋을 모두 지원해야 한다.
- 초기에는 Windows 기본 활동과 정상 시뮬레이터 프로필을 사용한다.

### FR-010 AI Provider
- AI가 없어도 수동·Mock 방식으로 핵심 파이프라인이 작동해야 한다.
- 외부 API와 로컬 LLM을 교체 가능한 Provider로 지원해야 한다.
- 기본 모드에서 AI는 룰 초안을 제안하고 자동 검증하며 최종 채택은 사용자가 승인한다.
- 자동 수정 반복은 실험 모드로 분리한다.

### FR-011 보고서
- 케이스별 Markdown 보고서를 생성해야 한다.
- 케이스별 독립형 HTML 파일을 생성해야 한다.
- 전체 케이스를 연결하는 정적 사이트를 생성해야 한다.
- 최종보고서와 논문 초안 자동 작성은 제외한다.

### FR-012 VM 자동화
- Windows 10 또는 11 x64 분석 VM 한 대를 등록해야 한다.
- VMware 기반 스냅숏 복원, 시작, 파일 전달, 명령 실행, 결과 회수, 종료를 지원해야 한다.
- 사용자가 매 실행 전에 승인해야 한다.
- 실행 제한 시간을 케이스별로 지정해야 한다.

### FR-013 네트워크 모드
- MVP에서 `disabled`와 `simulated` 모드를 지원해야 한다.
- 실제 외부 통신은 기본적으로 금지해야 한다.
- `restricted_external`, `custom`은 확장 후보이다.

### FR-014 공개 번들
- 보고서 전문, YARA·Sigma, 정제 이벤트, IOC, 검증 결과를 공개 번들로 생성해야 한다.
- 실제 악성 샘플, 원본 PCAP, 민감한 원본 로그는 제외해야 한다.

## 2. 비기능 요구사항

### NFR-001 안전성
모든 샘플 실행은 격리 VM, 사용자 승인, 시간 제한, 스냅숏 복원을 전제로 한다.

### NFR-002 재현성
동일한 입력과 프로필로 실행한 결과의 주요 설정, 도구 버전, 해시, 로그 범위를 기록해야 한다.

### NFR-003 이식성
프로젝트 작업공간은 상대 경로 기반으로 이동 가능해야 한다.

### NFR-004 추적성
룰, 검증 실행, 데이터셋, 근거, 보고서 간 관계를 추적할 수 있어야 한다.

### NFR-005 오프라인 동작
AI와 서버 연결 없이 핵심 파이프라인이 동작해야 한다.

### NFR-006 확장성
Hypervisor, Guest Agent, AI Provider, Execution Profile을 인터페이스로 분리해야 한다.

### NFR-007 사용자 통제
AI 결과, 샘플 실행, 룰 승인, 공개 번들은 사용자가 최종 확인해야 한다.
