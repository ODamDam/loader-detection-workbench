# 완료 정의

## 1. 공통 Definition of Done

작업은 다음 조건을 모두 충족해야 완료이다.

- 요구사항 또는 이슈의 완료 조건을 충족한다.
- 정상 입력과 오류 입력을 처리한다.
- 테스트가 통과한다.
- 결과가 SQLite와 파일 시스템에 올바르게 저장된다.
- 재실행 결과가 재현 가능하다.
- 오류 메시지가 원인과 대응 방향을 제공한다.
- 사용자 문서 또는 CLI 도움말이 갱신된다.
- 민감 데이터가 로그나 공개 산출물에 노출되지 않는다.
- 변경 이유가 이슈, 커밋, ADR 중 하나에 기록된다.

## 2. 케이스 완료 기준

- 정적 PE 분석이 존재한다.
- Sysmon 로그가 존재한다.
- 선택 수집 자료의 상태와 사유가 기록된다.
- 초기 실행 타임라인이 생성된다.
- 핵심 근거가 Evidence로 연결된다.
- Detection Hypothesis가 작성된다.
- YARA·Sigma가 연결된다.
- 정상 데이터 검증이 수행된다.
- 보고서가 생성된다.

## 3. 룰 검증 완료 기준

- 문법 검사를 통과한다.
- 목표 악성 사례를 탐지한다.
- 사례별 정상 대응 데이터를 시험한다.
- 공통 정상 데이터셋을 시험한다.
- 근거와 한계가 기록된다.
- 룰·데이터셋 버전이 저장된다.
- 사용자가 승인한다.

## 4. VM 자동 실행 완료 기준

- 승인 화면이 표시된다.
- VM과 스냅숏이 검증된다.
- 네트워크 모드가 정책과 일치한다.
- 게스트 해시가 일치한다.
- 제한 시간 내 실행된다.
- 결과 번들이 회수된다.
- VM이 Clean Snapshot으로 복원된다.
- 실패 시 부분 결과와 원인이 보존된다.

## 5. 릴리스 완료 기준

- 설치·실행 절차가 문서화된다.
- 데모 데이터로 제품을 실행할 수 있다.
- 공개 번들에 금지 자료가 없다.
- 6개 케이스 일괄 보고서 빌드가 성공한다.
- 버전과 변경 이력이 기록된다.
