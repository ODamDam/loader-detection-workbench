탐지 룰과 평가

분모가 다른 것은 대상 자료가 없는 Case(not_evaluable)를 제외하기 때문입니다. dev는 상세 분석 6건, 추가 dev는 3건, unseen은 룰 개발에 쓰지 않은 6건입니다. 정상 오탐은 unseen 평가에 함께 넣은 정상 Case 기준입니다.

해석할 때 주의할 점

  • dev와 추가 dev 수치는 룰을 만들 때 본 자료가 포함되어 성능 지표가 아닙니다.
  • RULE-0009와 RULE-0010은 추가 dev 사례에서 회수한 파일도 써서 작성했습니다.
  • RULE-0001의 추가 dev 매치 1건은 dev 샘플에 들어 있던 파일과 같은 파일이라 일반화 근거로 쓰지 않습니다.
  • 정상 호스트 파일을 따로 읽기 전용으로 검사했습니다. RULE-0009·0010은 242,421개, RULE-0011 v2와 RULE-0012 v1 조건은 242,204개에서 매치가 없었습니다.
  • unseen 1건은 VM 실행이 두 번 실패해 Sigma로 평가하지 못했습니다.
